### ZAir
This work is directly compatible with the [AirGradient ONE](https://www.airgradient.com/indoor/),
it was created in frustration of the size over the monitor,
and personal opinions on LED, including but not limited to screens.

It is indeed a fork of the work done by AirGradient themselves, without whom this project would not have happened.
It was redesigned in KiCAD and has been verified in production via JLCPCB.

All sensors have been integrated directly into the main board, this removes superfluous board ordering or assembly,
however, it also means that "upgrading" with new sensors is harder.
The dimensions have approximately been halved, decreasing the area to around a quarter of the original design.
More could probably be done, but inexperience, and assumptions that the people at AirGradient probably had some good
reason except just temperature made the sensor into the size it is today.
